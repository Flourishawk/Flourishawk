# Hi there👋I'm Mykhailo Ishchenko

I'm a data engineer with a background in analytics and a solid academic foundation in automation and computer-integrated technologies.

I design data pipelines from scratch and optimize those already running in production. I work on analytical warehouse modeling (star schema, incremental loads), orchestration in Apache Airflow, and deployments on GCP and AWS, with PostgreSQL as the primary relational store.
Before moving into engineering, I spent several years as an analyst: developing and optimizing SQL queries (PostgreSQL, MySQL), automating analytics in Python with API integrations, building dashboards in Metabase, organizing team workflow with Kanban (Trello), and conducting technical interviews with candidates for analyst positions.

I'm keen to keep growing in data engineering, combining technical skills with process-organization experience to support effective teams and projects.
